## About

This package is an original Kurdish (Sorani) localization made by
Ameer Xoshnaw for Games in Kurdish. It can include Kurdish translations,
subtitles, dubbing text, fonts, mods, tools, and related files.

All of the work in this package is my own original work.

## Requirements

- A legally owned copy of the game this package was made for
- The game version listed on the official download page

## Installation

1. Back up your original game files.
2. Extract the downloaded archive.
3. Copy the files into the game folder, replacing the original files when asked.
4. Start the game and select Kurdish in the language settings.

For consoles and mobile, follow the install steps on the official download page.

## Uninstall

Delete the files you copied, or restore your backup of the original files.
